# D2R Pickit 0.12.0 — Portable pickup rules and radius up to 9999

Back up your pickup rules before reinstalling, restore them across config changes, and choose a larger pickup radius.

## Import and export pickup rules

- Open **Ctrl+P → Item picker** and use **Export rules...** to save your category switches and Include/Exclude lists. Exports include the currently displayed rules, including unsaved changes.
- Use **Import rules...** to restore a rules export or an old full `auto-pickup-anything.toml`. Recognized rule fields are copied into the current config; unrelated/retired fields are skipped and missing rule fields keep their current values.
- Review imported selections, then **Apply & Save**. Pickit first backs up the full active config beside the TOML. A failed backup or config write leaves the previous gameplay policy active.
- Pickup radii, potion routing and Auto Interact settings retain their current values. Imports use exact item codes; review selections when moving between mods that assign different meanings to the same code.

## Pickup radius up to 9999

- Walking and built-in post-cast pickup now accept **1–9999**, with the default still **4**. Enter the values in **Ctrl+P → General**.
- The scan still searches neighboring game rooms and respects collision, inventory capacity and native pickup acceptance. A radius of 9999 does not promise map-wide pickup.
- Auto Interact retains its independent **Normal reach / 1–20** range. Compatibility with older standalone Teleport versions remains unchanged.

## Settings reliability

Keep invalid radius text visible until corrected or discarded. Cancel pending file dialogs when settings close and reject old actions after reopening a draft. Export files atomically, protect the active config from accidental export, and support Unicode file paths.

## Upgrading

Close the game, replace the Pickit DLL, and **keep your existing `auto-pickup-anything.toml`**. Export your rules to a folder outside the mod installation before reinstalling. A newly added config setting does not require replacing the whole TOML; missing supported settings use defaults.

The plugin ID, DLL and config filenames remain unchanged. Built-in Auto Interact, potion routing, Reimagined item support and standalone Teleport compatibility remain available. TCP/IP automatic opening remains unsupported.
