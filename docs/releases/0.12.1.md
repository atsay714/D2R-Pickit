# D2R Pickit 0.12.1 — Smaller rule exports and corrected metadata escaping

This update simplifies the portable pickup-rule exporter while retaining the
full TOML parser for imports. It includes the portable rule import/export and
pickup radius up to 9999 introduced in 0.12.0.

- Write the fixed export schema directly instead of including a general-purpose
  TOML formatter in the plugin binary.
- Correctly escape mod-name metadata containing quotes, backslashes, newlines
  and ASCII control characters. Preserve Unicode names and all pickup rules.
- Retain imports from exports and older full configs, staged review, automatic
  config backups, atomic exports and protection of the active config.

Close the game, replace the DLL, and **keep your existing
`auto-pickup-anything.toml`**. Existing rule exports remain compatible. Auto
Interact, potion routing and standalone Teleport compatibility are unchanged.

The exporter change follows controlled, reproducible Windows builds that
isolated the 0.12.0 antivirus detection to its compiled formatting path. It also
fixes a reproduced metadata serialization error. Bitdefender case 01198433
remains the vendor review for the original 0.12.0 file.
